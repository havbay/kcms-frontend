English type

Khmer is Noto Sans Khmer — the face you identified. Same headline, same body line, same interface row in each, so the English face is the only variable.

✓

Khmer settled: Noto Sans Khmer Variable. The font in your screenshot is the one already installed and imported at main.tsx:6. Google Sans sits ahead of it in the stack but has no Khmer glyphs, so every Khmer character has always been drawn by Noto Sans Khmer — it is now named first for Khmer text, which changes nothing visually and removes a silent fallback. Variable 100–900, so headline and body weights come from one file. Latin text comes from whichever English face you pick below; say so if you want Google Sans kept for Latin as well.
