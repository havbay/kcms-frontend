# KCMS V2 Frontend

React 19 and TypeScript frontend for the KCMS V2 Khmer and Khmerlish Facebook
comment-moderation platform.

## Requirements

- Node.js 22.12 or newer
- npm 10 or newer
- Google Chrome for Playwright checks

## Commands

```bash
npm install
npm run dev
npm test
npm run test:e2e
npm run typecheck
npm run lint
npm run build
```

The current implemented slice is the bilingual public landing-page header and
hero. Request Access and Sign In routes are intentional navigation targets for
later slices and are not implemented yet.
